## 2. Швидке підключення: 5 дій

Щоб підключити Search Console без ручної роботи з DNS, використати Google Analytics 4 ресурсу MAX SITE `548154976` (`G-TS8DMMKK34`).

Обов’язкова умова: відкрити Search Console у тому самому Google-акаунті, який має право **Редактор** на ресурс Google Analytics MAX SITE.

1. Відкрити `https://search.google.com/search-console/` і натиснути **Додати ресурс**.
2. Обрати **Ресурс із префіксом URL**, вставити `https://maxsite.com.ua/` і натиснути **Продовжити**.
3. У способах підтвердження розгорнути **Google Analytics**.
4. Натиснути **Підтвердити**.
5. Після повідомлення про успішне підтвердження натиснути **Перейти до ресурсу**.

Код Analytics уже присутній на сайті, тому додавати тег повторно або запускати новий deployment не потрібно.

Після цих 5 дій базове підключення завершене. Sitemap уже оголошений у `robots.txt` як `https://maxsite.com.ua/sitemap.xml`, тому Google може знайти його автоматично.

Ручне надсилання sitemap — необов’язкова додаткова перевірка:

1. Відкрити **Індексування → Файли Sitemap**.
2. Ввести `sitemap.xml` і натиснути **Надіслати**.

Якщо Google Analytics не підтвердить право власності, спочатку перевірити, що вибраний правильний Google-акаунт і він має роль **Редактор** для GA4 MAX SITE. Не додавати ще один Google tag на сайт.

## 3. Повне доменне покриття — другий етап

Створити в Google Search Console ресурс типу **Домен**:

`maxsite.com.ua`

Не вводити `https://`, `www` або шлях сторінки. Доменний ресурс охоплює `http`, `https`, основний домен і можливі піддомени. Для нього потрібне підтвердження через DNS TXT.

Цей ресурс варто додати після швидкого підключення. Google не дозволяє підтвердити доменний ресурс через Analytics — тільки через DNS. Для поточного production-сайту ресурс із префіксом `https://maxsite.com.ua/` уже охоплює всі основні canonical URL.

## 4. Що потрібно мати перед початком

- доступ до Google-акаунта, на якому буде Search Console;
- доступ до NIC.UA для домену `maxsite.com.ua`;
- відкритий сайт `https://maxsite.com.ua/`;
- цей документ для копіювання URL;
- можливість зробити скріншоти підтвердження, sitemap та URL Inspection.

Не надсилати в чат паролі, коди входу або повний доступ до Google/NIC.UA.

## 5. Підтвердження домену через DNS

1. Відкрити `https://search.google.com/search-console/`.
2. Натиснути **Додати ресурс**.
3. У колонці **Домен** ввести `maxsite.com.ua`.
4. Скопіювати TXT-значення, яке надасть Google. Воно матиме вигляд:

   `google-site-verification=ВАШ_УНІКАЛЬНИЙ_КОД`

5. У NIC.UA відкрити домен `maxsite.com.ua` і перейти до керування DNS-записами.
6. Додати запис:

| Поле | Значення |
|---|---|
| Тип | `TXT` |
| Ім’я / Host | `@` або порожнє поле — відповідно до форми NIC.UA |
| Значення | повний рядок `google-site-verification=...` |
| TTL | стандартний / Auto |

7. Зберегти запис.
8. Не видаляти чинні A, CNAME або MX-записи.
9. Почекати поширення DNS і натиснути **Підтвердити** у Search Console.
10. Після успіху залишити TXT-запис у DNS постійно.

Якщо Google не підтвердить домен одразу, не створювати дублікати TXT. Спочатку перевірити поширення запису й повторити підтвердження пізніше.

## 6. Sitemap

Після підтвердження ресурсу:

1. Відкрити **Індексування → Файли Sitemap**.
2. У полі нового sitemap ввести:

   `sitemap.xml`

3. Натиснути **Надіслати**.
4. Зафіксувати статус, дату відправлення та кількість виявлених сторінок.

Очікуваний повний URL:

`https://maxsite.com.ua/sitemap.xml`

Очікувана кількість URL на момент підключення: **40**.

## 7. URL Inspection — пріоритет першого дня

Перевірити live URL та запросити індексацію в такому порядку:

1. `https://maxsite.com.ua/`
2. `https://maxsite.com.ua/stvorennya-saytiv/`
3. `https://maxsite.com.ua/stvorennya-landing-page/`
4. `https://maxsite.com.ua/stvorennya-saytu-dlya-biznesu/`
5. `https://maxsite.com.ua/stvorennya-korporatyvnoho-saytu/`
6. `https://maxsite.com.ua/stvorennya-internet-mahazynu/`

Для кожної сторінки перевірити:

- live test успішний;
- сторінка дозволена до індексації;
- Googlebot може завантажити сторінку;
- user-declared canonical збігається з поточною HTTPS-адресою;
- немає `noindex`;
- після перевірки натиснути **Запросити індексацію**.

Не запитувати індексацію старих URL:

- `/stvorennya-sajtiv-pid-klyuch/`;
- `/stvorennya-lendingiv/`;
- `/korporatyvni-sajty/`;
- `/internet-magazyn-pid-klyuch/`.

Вони навмисно мають `noindex, follow` і canonical на нові сторінки.

## 8. Початкові налаштування Search Console

Після підключення перевірити:

- **Налаштування → Користувачі та дозволи** — власник має правильний Google-акаунт;
- **Індексування → Сторінки** — зафіксувати початковий стан;
- **Покращення** — перевірити структуровані дані, якщо звіти вже доступні;
- **Безпека та ручні заходи** — не повинно бути активних проблем;
- **Посилання** — дані можуть з’явитися пізніше;
- **Ефективність** — для нового ресурсу дані можуть бути відсутні кілька днів.

Не очікувати миттєвих позицій або повного звіту одразу після підтвердження. Додавання ресурсу й sitemap не гарантує індексацію кожної сторінки.
