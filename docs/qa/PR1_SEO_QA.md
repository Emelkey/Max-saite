## Фактична перевірка домену

| Варіант | Результат |
| --- | --- |
| `https://maxsite.com.ua/` | 200 |
| `https://www.maxsite.com.ua/*` | 301 на `https://maxsite.com.ua/*`, шлях і query зберігаються |
| `http://maxsite.com.ua/*` | 200 — потрібне ручне увімкнення Enforce HTTPS |
| `http://www.maxsite.com.ua/*` | 301 на `http://maxsite.com.ua/*`; після Enforce HTTPS має вести на HTTPS |
| Googlebot для головної | 200 |
| Невідомий URL | 404 |
| SSL | Let’s Encrypt, SAN: `maxsite.com.ua`, `www.maxsite.com.ua` |

DNS: чотири GitHub Pages A-записи для apex; `www` CNAME → `emelkey.github.io`.

## Потребує ручного налаштування

1. У GitHub → Settings → Pages увімкнути **Enforce HTTPS** після завершення DNS check. Це виправить `http://maxsite.com.ua` і прибере небезпечне друге дзеркало.
2. Додати/перевірити repository variable `SEARCH_CONSOLE_TOKEN` і підтвердити доменний ресурс у Google Search Console через DNS TXT.
3. Після злиття PR надіслати `https://maxsite.com.ua/sitemap.xml` у Search Console та перевірити URL Inspection для головної й ключових сторінок.
4. PR не зливати в `main` без окремого підтвердження власника.
