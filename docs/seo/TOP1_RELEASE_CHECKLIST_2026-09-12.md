- GSC 13.08–09.09.2026: 1 клік / 2 084 покази / CTR 0,0480% / позиція 65,60. Це перекривний дорелізний зріз, а не приріст від змін. Звіти сторінок/запитів не сумуються в загальний підсумок ресурсу; неповні/анонімізовані рядки не перетворюються на нулі.
- GA4 13.08–09.09.2026, property 548154976, hostName=maxsite.com.ua: 3 події `generate_lead` у Paid Search/Direct; 4 `click_phone`, з них 1 Organic Search. Це зареєстровані події, не підтверджені унікальні ліди, дзвінки або продажі. Історичні синтетичні дії на production неможливо відокремити цим зрізом. Localhost виключений. Зв'язок measurement ID зі stream треба окремо підтвердити через Admin.
- Дати GSC — America/Los_Angeles; GA4 — Europe/Kiev. Порівнювати числа двох систем як тотожні не можна. [Офіційне визначення GSC](https://developers.google.com/webmaster-tools/v1/searchanalytics/query).

## Приймання перед релізом

- `npm run seo:check`: PASS; 75 unit tests, 112 HTML у production package, 90 sitemap URL.
- `npm run test:browser`: 100 PASS, 6 платформних SKIP; desktop/mobile, переповнення, помилки console, форми з mock endpoint, consent, події без PII, контактні контролі 320–768 px. Реальні заявки не надсилались.
- `npm run lighthouse`: шість маршрутів, по три mobile запуски; median performance 99, accessibility 93–97, best practices 100, SEO 100. Це лабораторні результати, не польові CWV.
- Dashboard: збирання та перевірка authored contract PASS. Ручний перегляд у вбудованому браузері заблокований перевіркою адміністративної політики; коректний рендеринг графіків/візуальне приймання поки не підтверджені. Панель не включена в публічний hosting package.
- CI, точний deployment SHA, production hash/HTTP crawl та annotation фіксуються після реального релізу в GitHub Actions і `seo-monitoring/` проєкту. Цей дорелізний файл не є їх доказом.

## Що залишається у повному ТЗ

1. Два додаткові завершені клієнтські проєкти, дозволи на публікацію, справжні before/after метрики й підтверджена біографія засновника. Запит фактів власнику надіслано; дані не вигадуються.
2. Окреме дослідження цін 50 студій і квартальний market report, відтворювані Next.js/WordPress та CWV експерименти. Наявні шаблони й одноразова SERP-вибірка їх не замінюють.
3. S6 на 90 днів: 3–5 погоджених client backlinks, 5–10 реальних профілів, 3–5 партнерських згадок, 2–4 експертні розміщення. Дозволи, власність акаунтів і ручний outreach потрібні до публікації; повідомлення третім сторонам не надсилались. Вести наявний `master-4-0-outreach-log.csv`, записувати лише підтверджені розміщення.
4. Повторні SERP-вимірювання на інших датах; перевірка GSC indexing після нового crawl, польові CrUX/CWV за наявності достатніх даних. Стара Google-інспекція noindex від серпня не означає noindex нового live HTML.
5. KPI gates через 14–30, 30–60, 60–120 та 120–240 днів від підтвердженого deployment. Нові міста, масові snippet-тести й твердження про TOP1 потребують спостережуваного результату.
