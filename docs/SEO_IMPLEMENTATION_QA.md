## 4. SEO-ризики, які залишаються

1. Результат ранжування не з’явиться одразу після деплою: Google має повторно просканувати сторінки.
2. Legacy URL із canonical на primary можуть певний час відображатися як альтернативні сторінки. На цьому етапі їх не видаляємо й не перенаправляємо без окремої карти редиректів.
3. Для Києва не створюємо фіктивну адресу або офіс. Локальна релевантність будується контентом, послугами та внутрішніми посиланнями.
4. Не створено нових міст або ніш, щоб не розмножувати тонкі сторінки.
5. Дані про позиції, трафік і конверсії не вигадуються. Реальні кейси треба доповнювати підтвердженими результатами, коли вони з’являться.
6. Після деплою потрібно перевірити рендеринг, статуси live URL, sitemap і фактичне надходження подій GA4.
