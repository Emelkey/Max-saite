## SEO та міграція

- Один власник для кожного пошукового наміру.
- Title, description, H1, self-canonical та правила індексації.
- Старі URL → найближчі релевантні нові URL, без ланцюгів.
- Справжня HTTP 404; sitemap лише для indexable canonical URL.
- Schema відповідає видимому змісту; відгуки лише підтверджені.
