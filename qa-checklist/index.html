Чекліст контролю якості сайту

Публічний чекліст MAX SITE: SEO, мобільна версія, форми, аналітика, безпека й production-перевірка.

Перевірні правила

Показуємо процес без вигаданих показників і гарантій позицій.

Технічна доступність

  • HTTPS і один основний домен
  • Коректні 200, 301 і справжня 404
  • Немає битих внутрішніх посилань
  • Production не містить тестових URL

SEO та індексація

  • Унікальні title, description і один H1
  • Self-canonical на індексованих сторінках
  • Sitemap містить лише 200 indexable URL
  • Robots.txt посилається на sitemap
  • Schema відповідає видимому контенту

Конверсії та мобільний QA

  • Меню, телефон, Telegram і форма працюють
  • Перевірені ширини 360, 390, 430, планшет і desktop
  • Немає горизонтального скролу
  • GA4 отримує ключові події без персональних даних
  • Заявка доходить до production endpoint

Цей список описує процес, а не сертифікат для кожного майбутнього релізу. Фактичний результат кожного запуску фіксується окремим QA-звітом.
